# Haqak — English Summary

Haqak is an **independent** Egypt‑focused Civic‑Tech MVP/Prototype (Egypt only for now).

It aims to improve how local issues are submitted, tracked, and resolved — with clearer workflows, accountability concepts, and analytics built in.

**Not affiliated with any government entity.**  
"MP" (نائب) in this platform refers to a **user role** (Members of Parliament as platform participants), not an official government integration.

## What it does
- Citizens submit and track local issues/complaints
- MPs (as platform users) receive, organise, and respond to issues
- Admins oversee governance and policies
- Transparency layer: Hash Chain concept for logging key events
- Maps + charts for data visualisation
- i18n ready (Arabic-first + English)

## Tech Stack
React · TypeScript · Vite · Tailwind · shadcn/ui  
Supabase · React Query · i18next · Leaflet · Recharts  
Vitest

## Quick Start
```bash
git clone https://github.com/SynapBytes/haqak.git
cd haqak
npm install
cp .env.example .env
npm run dev
```
