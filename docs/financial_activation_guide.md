# دليل خطوات التفعيل المالي لمشروع Haqak

يهدف هذا الدليل إلى توضيح الخطوات العملية التي يجب اتخاذها لتفعيل النظام المالي المتكامل لمشروع Haqak بعد استكمال الإجراءات القانونية للشركة.

## 1. الإجراءات القانونية والتجارية الأساسية

قبل البدء في أي تكاملات مالية، يجب استكمال الخطوات القانونية والتجارية التالية:

1.  **تأسيس الشركة رسمياً:** يجب الحصول على السجل التجاري والبطاقة الضريبية لشركة Haqak. هذه المستندات هي الأساس لأي تعاملات بنكية أو مالية رسمية.
2.  **فتح حساب بنكي للشركة في CIB:** يجب فتح حساب بنكي تجاري باسم الكيان القانوني لشركة Haqak في البنك التجاري الدولي (CIB). هذا الحساب سيكون الحساب الرئيسي الذي ستتم من خلاله جميع التعاملات المالية للمنصة.

## 2. تفعيل خدمات البنك التجاري الدولي (CIB)

بعد فتح الحساب البنكي، يجب تفعيل الخدمات التالية مع CIB:

1.  **طلب خدمة CIB Corporate Gateway:** هذه الخدمة ضرورية للتكامل المباشر بين منصة Haqak وبوابة الدفع الخاصة بـ CIB. ستمكن هذه الخدمة من تحصيل المدفوعات بشكل آلي وسريع.
2.  **فتح حساب Escrow فرعي (Sub-account):** لضمان الشفافية والمساءلة، يجب طلب فتح حساب فرعي مخصص (Escrow Account) ضمن حساب الشركة الرئيسي. هذا الحساب سيتم استخدامه لحفظ أموال المشاريع بشكل منفصل عن أموال تشغيل الشركة.
3.  **الحصول على IPA (Instant Payment Address):** لتسهيل تكامل InstaPay، يجب طلب عنوان دفع لحظي (IPA) خاص بحساب الشركة في CIB. هذا العنوان سيكون بمثابة معرف فريد للشركة على شبكة InstaPay (مثلاً: `yourcompanyname@cib`).

## 3. تفعيل خدمات فوري (Fawry)

لتمكين الدفع عبر شبكة فوري، يجب اتباع الخطوات التالية:

1.  **التعاقد مع فوري:** التواصل مع شركة فوري للتعاقد على خدمات Fawry Pay (للدفع النقدي عبر الأكشاك) و Fawry Accept (للدفع الإلكتروني عبر البطاقات).
2.  **الحصول على Merchant Code و Security Key:** بعد التعاقد، ستقوم فوري بتزويدكم بـ `Merchant Code` و `Security Key`. هذه البيانات ضرورية لربط نظام Haqak ببوابة فوري وتوثيق المعاملات.
3.  **تحديد Callback URL:** يجب تزويد فوري بعنوان URL الخاص بنظام Haqak (مثلاً: `https://api.haqak.com/fawry/callback`) لتلقي إشعارات الدفع الفورية وتحديث حالة المساهمات في الوقت الحقيقي.

## 4. تفعيل خدمات إنستاباي (InstaPay)

تفعيل InstaPay يعتمد بشكل كبير على التكامل مع CIB:

1.  **التكامل مع البنك:** بما أن InstaPay يعمل كشبكة دفع فورية تربط بين البنوك، فإن تفعيله يعتمد على جاهزية حساب CIB الخاص بالشركة لاستقبال التحويلات عبر هذه الشبكة.
2.  **الحصول على API Key و Webhook Secret (إن وجد):** قد يتطلب الأمر بعض التنسيق مع CIB أو البنك المركزي المصري للحصول على مفاتيح الـ API اللازمة لتتبع التحويلات الواردة عبر InstaPay آلياً. هذا يضمن أن نظام Haqak يمكنه التحقق من التحويلات وتسجيلها في سجل البلوكشين.

## 5. تحديث إعدادات النظام

بعد الحصول على جميع البيانات والمفاتيح المذكورة أعلاه، يجب تحديث ملف الإعدادات الخاص بنظام Haqak. يمكن استخدام ملف `config.json` (كما هو موضح في وثيقة تصميم النظام المالي) أو متغيرات البيئة (Environment Variables) لتخزين هذه القيم:

*   `project_name`: الاسم الرسمي للمشروع (الاسم الجديد).
*   `project_domain`: الدومين الرسمي للمنصة.
*   `cib_bank_account.account_number`: رقم الحساب البنكي لشركة Haqak في CIB.
*   `cib_bank_account.account_holder`: اسم الشركة كما هو مسجل في البنك.
*   `cib_bank_account.ipa_address`: عنوان IPA الخاص بالشركة (مثلاً: `yourcompanyname@cib`).
*   `fawry_integration.merchant_code`: الكود التجاري من فوري.
*   `fawry_integration.security_key`: مفتاح الأمان من فوري.
*   `fawry_integration.callback_url`: رابط رد الاتصال من فوري.
*   `instapay_integration.api_key`: مفتاح API الخاص بـ InstaPay (إن وجد).
*   `instapay_integration.webhook_secret`: مفتاح Webhook السري الخاص بـ InstaPay (إن وجد).

بمجرد تحديث هذه الإعدادات، سيكون النظام المالي لمشروع Haqak جاهزاً للعمل بكامل طاقته، مما يضمن تحصيل المدفوعات بشفافية وأمان وسرعة.
