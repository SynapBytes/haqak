# نظام المساهمة في تطوير حقك (Haqak Contribution System)

تم تصميم هذا النظام لدعم استدامة واستقلال منصة "حقك" من خلال مساهمات المجتمع، مع التركيز على الرقي، الشفافية، والخصوصية.

## المكونات التقنية

### 1. قاعدة البيانات (Supabase)
تم إضافة جدولين جديدين:
- `contributions`: لتخزين بيانات المساهمات (المبلغ، الحالة، الاسم الاختياري، إلخ).
- `feedbacks`: لتخزين الملاحظات والرسائل التي يرسلها المساهمون بعد إتمام العملية.

### 2. الواجهة الأمامية (React + Tailwind)
- **صفحة المساهمة (`/support`)**: واجهة متكاملة تتيح اختيار مبالغ مقترحة أو إدخال مبلغ مخصص، مع خيارات الخصوصية.
- **قسم الفوتر**: بطاقة أنيقة في أسفل الصفحة الرئيسية تدعو المستخدمين لدعم المنصة.
- **قائمة المساهمين**: عرض أسماء المساهمين الذين وافقوا على إظهار أسمائهم فقط.

## الأمان والخصوصية
- **الخصوصية أولاً**: الاسم والبريد الإلكتروني اختياريان تماماً.
- **التنقية (Sanitization)**: يتم تنقية كافة المدخلات النصية (الاسم، الرسالة) باستخدام مكتبة `DOMPurify` قبل التخزين والعرض لمنع هجمات XSS.
- **الحماية**: تم تفعيل Row Level Security (RLS) على الجداول لضمان أن البيانات الحساسة لا تظهر للعامة.

## ربط مزود الدفع (Future Integration)
حالياً، النظام يستخدم "Placeholder" لعملية الدفع ويقوم بتسجيل المساهمة كـ `succeeded` مباشرة للمحاكاة. لربط مزود دفع حقيقي (مثل Paymob أو Fawry):
1. قم بتحديث دالة `handleContribute` في `src/pages/Support.tsx`.
2. استدعِ API المزود للحصول على رابط الدفع أو Token.
3. وجّه المستخدم لصفحة الدفع.
4. استخدم Webhooks لتحديث حالة المساهمة في جدول `contributions`.

## إدارة قائمة المساهمين
- تظهر الأسماء فقط في حالة تفعيل خيار `show_name`.
- يمكن للإدارة مراجعة المساهمات والرسائل من خلال لوحة تحكم الأدمن (مستقبلاً) أو مباشرة عبر Supabase Dashboard.
