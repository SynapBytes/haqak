# Glossary — مصطلحات المنتج (مصري)

## المصطلحات الأساسية

| المصطلح | المعنى جوّه المنتج |
|---|---|
| **قضية / شكوى / طلب** | أي حاجة المواطن بيبعتها (بلاغ خدمة / مشكلة / مقترح…) |
| **حالة القضية (Status)** | المرحلة اللي وصلت لها القضية (جديد / قيد المراجعة / تمت الإحالة / مغلقة…) |
| **دائرة** | نطاق جغرافي/تمثيل حسب تعريف المنتج |
| **نائب (MP)** | نائب مجلس الشعب — **فئة مستخدمين (User Role)** جوّه النظام، مش تكامل حكومي رسمي |
| **مواطن (Citizen)** | المستخدم العادي اللي بيقدم ويتابع القضايا |
| **إدارة (Admin)** | المشرف على النظام وسياساته |
| **مساءلة (Accountability)** | في سجل واضح للأحداث والتحديثات، مين عمل إيه وإمتى |
| **Ledger (Hash Chain)** | فكرة لتوثيق أحداث مهمة بسجل صعب يتزوّر — كل حدث مرتبط بـ hash بالحدث اللي قبله |
| **اعتماد (Verification)** | تأكيد هوية حساب النائب قبل ما يفتح له كل الصلاحيات |
| **أولويات (Priorities)** | ترتيب القضايا حسب الأهمية والانتشار في الدائرة |

---

## مصطلحات تقنية مهمة

| المصطلح | المعنى |
|---|---|
| **MVP** | Minimum Viable Product — النسخة الأولى القابلة للتشغيل والتجربة |
| **RLS** | Row Level Security — حماية البيانات على مستوى الصف في Supabase |
| **Edge Function** | كود backend بيشتغل على الـ edge (Supabase Functions) |
| **i18n** | Internationalization — دعم أكتر من لغة (عربي + إنجليزي حاليًا) |
| **PWA** | Progressive Web App — الموقع يشتغل زي تطبيق على الموبايل |
| **Civic‑Tech** | تقنية في خدمة المجتمع المدني |
