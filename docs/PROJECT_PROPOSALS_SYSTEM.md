# نظام اقتراح المشاريع المجتمعية - التوثيق الشامل

## 1. نظرة عامة

يوفر نظام اقتراح المشاريع المجتمعية منصة متكاملة تمكّن المواطنين من اقتراح مشاريع لتطوير دائرتهم، والتصويت عليها، وتمويلها بشكل جماعي. يجمع النظام بين الذكاء الاصطناعي والشفافية والديمقراطية التشاركية.

### المميزات الرئيسية:

- **اقتراح ذكي**: المواطنون يقترحون المشاريع بلغة بسيطة، والذكاء الاصطناعي يحسنها احترافياً
- **تصويت جغرافي**: التصويت مقصور على سكان المنطقة المعنية فقط
- **تمويل جماعي آمن**: جمع التبرعات عبر بوابات دفع محلية موثوقة (Fawry, CIB, InstaPay)
- **شفافية كاملة**: كل عملية مسجلة في البلوكشين
- **إشعارات مرحلية**: تحديثات فورية عند كل مرحلة من مراحل المشروع

## 2. دورة حياة المشروع

```
┌─────────────────────────────────────────────────────────────────┐
│                    دورة حياة المشروع                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. الاقتراح (Proposal)                                        │
│     └─> المواطن يقترح المشروع                                  │
│     └─> AI يحسن المحتوى والميزانية                             │
│     └─> الإدارة تراجع المقترح                                  │
│                                                                 │
│  2. التصويت (Voting)                                           │
│     └─> الموافقة على بدء التصويت                              │
│     └─> إشعارات للمواطنين في المنطقة                          │
│     └─> التصويت (7 أيام)                                      │
│     └─> النتيجة: 51% موافقة = بدء التمويل                     │
│                                                                 │
│  3. التمويل (Funding)                                          │
│     └─> بدء جمع التبرعات                                       │
│     └─> شريط تقدم يعرض المبلغ المجمع                          │
│     └─> تحديثات يومية للمساهمين                               │
│     └─> عند الوصول للهدف: بدء التنفيذ                        │
│                                                                 │
│  4. التنفيذ (Execution)                                        │
│     └─> تقسيم المشروع لمراحل                                   │
│     └─> تصويت على كل مرحلة قبل الدفع                          │
│     └─> إشعارات عند إنجاز كل مرحلة                             │
│                                                                 │
│  5. الإنجاز (Completion)                                       │
│     └─> المشروع منجز                                           │
│     └─> تقرير نهائي شامل                                       │
│     └─> شكر المساهمين والمنفذين                               │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 3. قاعدة البيانات

### الجداول الرئيسية:

#### 3.1 `project_proposals` - مقترحات المشاريع

| الحقل | النوع | الوصف |
|------|------|-------|
| `id` | UUID | معرّف فريد للمشروع |
| `user_id` | UUID | معرّف المواطن الذي اقترح المشروع |
| `title` | TEXT | عنوان المشروع الأصلي |
| `description` | TEXT | وصف المشروع الأصلي |
| `ai_refined_title` | TEXT | العنوان المحسّن بالذكاء الاصطناعي |
| `ai_refined_description` | TEXT | الوصف المحسّن بالذكاء الاصطناعي |
| `ai_budget_estimate` | DECIMAL | تقدير الميزانية من الذكاء الاصطناعي |
| `ai_impact_analysis` | TEXT | تحليل الأثر المتوقع |
| `category` | TEXT | فئة المشروع (بنية تحتية، تعليم، إلخ) |
| `location` | TEXT | موقع المشروع |
| `latitude` | DOUBLE | خط العرض |
| `longitude` | DOUBLE | خط الطول |
| `target_amount` | DECIMAL | الميزانية المطلوبة |
| `raised_amount` | DECIMAL | المبلغ المجمع حتى الآن |
| `status` | TEXT | حالة المشروع (انظر الحالات أدناه) |
| `voting_deadline` | TIMESTAMP | آخر موعد للتصويت |
| `funding_deadline` | TIMESTAMP | آخر موعد لجمع التبرعات |
| `created_at` | TIMESTAMP | تاريخ الإنشاء |
| `updated_at` | TIMESTAMP | تاريخ آخر تحديث |

#### حالات المشروع:

- `pending_review`: في انتظار مراجعة الإدارة
- `voting_active`: قيد التصويت المجتمعي
- `voting_failed`: لم يحصل على نسبة التصويت المطلوبة
- `funding_active`: قيد جمع التبرعات
- `funding_completed`: اكتملت الميزانية
- `in_progress`: المشروع قيد التنفيذ
- `completed`: اكتمل المشروع
- `rejected`: تم رفضه من قبل الإدارة
- `funding_failed`: لم يصل للميزانية المطلوبة
- `cancelled`: تم إلغاؤه

#### 3.2 `project_votes` - أصوات المشاريع

| الحقل | النوع | الوصف |
|------|------|-------|
| `id` | UUID | معرّف فريد للصوت |
| `project_id` | UUID | معرّف المشروع |
| `user_id` | UUID | معرّف المصوّت |
| `vote_type` | TEXT | نوع الصوت: `upvote` أو `downvote` |
| `created_at` | TIMESTAMP | تاريخ الصوت |

#### 3.3 `project_contributions` - المساهمات المالية

| الحقل | النوع | الوصف |
|------|------|-------|
| `id` | UUID | معرّف فريد للمساهمة |
| `project_id` | UUID | معرّف المشروع |
| `user_id` | UUID | معرّف المساهم |
| `amount` | DECIMAL | مبلغ المساهمة |
| `payment_status` | TEXT | حالة الدفع: `pending`, `completed`, `refunded`, `failed` |
| `payment_reference` | TEXT | رقم مرجعي من بوابة الدفع |
| `created_at` | TIMESTAMP | تاريخ المساهمة |
| `updated_at` | TIMESTAMP | تاريخ آخر تحديث |

#### 3.4 `project_milestones` - مراحل المشروع

| الحقل | النوع | الوصف |
|------|------|-------|
| `id` | UUID | معرّف فريد للمرحلة |
| `project_id` | UUID | معرّف المشروع |
| `title` | TEXT | عنوان المرحلة |
| `description` | TEXT | وصف المرحلة |
| `percentage_of_total` | DECIMAL | نسبة الدفع من الميزانية الكلية |
| `status` | TEXT | حالة المرحلة: `pending`, `in_progress`, `completed`, `verified` |
| `evidence_urls` | TEXT[] | روابط الصور/الفيديوهات كدليل |
| `created_at` | TIMESTAMP | تاريخ الإنشاء |
| `updated_at` | TIMESTAMP | تاريخ آخر تحديث |

## 4. المكونات الواجهة (React Components)

### 4.1 ProjectProposalForm

**الملف**: `/src/components/ProjectProposalForm.tsx`

**الوظيفة**: نموذج تقديم مقترح مشروع جديد

**الخطوات**:
1. إدخال بيانات المشروع (العنوان، الوصف، الفئة، الموقع، الميزانية)
2. معالجة بالذكاء الاصطناعي (تحسين النص، تقدير الميزانية، تحليل الأثر)
3. مراجعة التحسينات
4. التقديم النهائي

**Props**: لا توجد

**الحالة المحلية**:
- `step`: مرحلة النموذج (form, ai-review, confirmation)
- `formData`: بيانات المشروع المدخلة
- `aiRefinement`: البيانات المحسّنة من الذكاء الاصطناعي

### 4.2 ProjectVotingSystem

**الملف**: `/src/components/ProjectVotingSystem.tsx`

**الوظيفة**: نظام التصويت على المشاريع المقترحة

**الخصائص**:
- عرض المشاريع قيد التصويت
- تصويت فوري (تأييد/رفض)
- عرض نسبة التصويت
- إشعارات فورية

**Props**: لا توجد

**البيانات المتحققة**:
- المشاريع في حالة `voting_active`
- أصوات المستخدم السابقة
- إجمالي الأصوات لكل مشروع

### 4.3 ProjectCrowdfunding

**الملف**: `/src/components/ProjectCrowdfunding.tsx`

**الوظيفة**: نظام التمويل الجماعي

**الخصائص**:
- عرض المشاريع قيد جمع التبرعات
- شريط تقدم يعرض المبلغ المجمع
- مساهمة بمبالغ محددة أو مخصصة
- عرض مساهمات المستخدم السابقة

**Props**: لا توجد

**البيانات المتحققة**:
- المشاريع في حالة `funding_active`
- إجمالي المبالغ المجمعة
- مساهمات المستخدم

### 4.4 ProjectCommunityFeed

**الملف**: `/src/components/ProjectCommunityFeed.tsx`

**الوظيفة**: صفحة المجتمع لتتبع تحديثات المشاريع

**الخصائص**:
- عرض جميع تحديثات المشاريع
- تصفية حسب نوع التحديث
- ترتيب حسب الأحدث أو الأكثر تفاعلاً
- إمكانية الإعجاب والتعليق

**Props**: لا توجد

**البيانات المتحققة**:
- جميع المشاريع مرتبة حسب التاريخ
- عدد الإعجابات والتعليقات

## 5. تكامل الذكاء الاصطناعي (Gemini API)

### 5.1 معالجة المقترحات

يتم استخدام Google Gemini API لـ:

1. **إعادة الصياغة**: تحويل لغة المواطن البسيطة إلى نص احترافي
2. **تقدير الميزانية**: تحليل نوع المشروع والموقع لتقدير تكلفة واقعية
3. **تحليل الأثر**: وصف الفوائد المتوقعة للمجتمع

### 5.2 المتطلبات

```env
# Server-side only
OPENAI_API_KEY=your_openai_api_key
```

### 5.3 مثال على الاستدعاء

```typescript
const { data, error } = await supabase.functions.invoke('refine-project-proposal', {
  body: {
    title,
    description,
    category,
    location,
    targetAmount
  },
  headers: { 'X-CSRF-Token': csrfToken }
});
```

## 6. نظام الإشعارات

### 6.1 أنواع الإشعارات

| النوع | الوقت | المستقبلون |
|------|------|----------|
| `proposal_submitted` | عند تقديم مقترح | الإدارة والنواب |
| `voting_started` | عند بدء التصويت | سكان المنطقة |
| `voting_ended` | عند انتهاء التصويت | المساهمون |
| `funding_started` | عند بدء التمويل | سكان المنطقة |
| `milestone_completed` | عند إنجاز مرحلة | المساهمون |
| `project_completed` | عند انتهاء المشروع | المساهمون والمجتمع |
| `refund_initiated` | عند بدء استرجاع الأموال | المساهمون |

### 6.2 قنوات الإشعارات

- **Push Notifications**: إشعارات المتصفح الفورية
- **In-App Notifications**: إشعارات داخل التطبيق
- **Email**: بريد إلكتروني للتحديثات المهمة
- **SMS**: رسائل نصية للتحديثات الحرجة

## 7. سياسة الاسترجاع (Refund Policy)

### 7.1 حالات الاسترجاع

1. **عدم الوصول للميزانية**: إذا لم يصل المشروع لـ 80% من الهدف قبل انتهاء المهلة
2. **إلغاء المشروع**: إذا قررت الإدارة إلغاء المشروع
3. **فشل التنفيذ**: إذا توقف المشروع عن التقدم لأكثر من 30 يوم

### 7.2 عملية الاسترجاع

1. **فتح تصويت الاسترجاع**: يصوت المساهمون على الاسترجاع (51% موافقة)
2. **معالجة الاسترجاع**: خصم 2.5% رسوم تشغيل، واسترجاع الباقي
3. **الإشعار**: إخطار المساهمين بتفاصيل الاسترجاع

## 8. الأمان والشفافية

### 8.1 تشفير البيانات

- جميع بيانات المستخدمين مشفرة
- بيانات الدفع لا تُخزن محلياً
- استخدام HTTPS لجميع الاتصالات

### 8.2 البلوكشين

- جميع المعاملات المالية مسجلة في البلوكشين
- كل تصويت مسجل ولا يمكن تعديله
- سجل تدقيق كامل لجميع الإجراءات

### 8.3 التحقق من الهوية

- التحقق من رقم الهوية الوطنية
- التحقق من موقع المستخدم الجغرافي
- التحقق من رقم الهاتف

## 9. واجهات برمجية (APIs)

### 9.1 المشاريع

```
GET /api/projects - الحصول على جميع المشاريع
GET /api/projects/:id - الحصول على مشروع محدد
POST /api/projects - إنشاء مشروع جديد
PUT /api/projects/:id - تحديث مشروع
DELETE /api/projects/:id - حذف مشروع
```

### 9.2 التصويت

```
POST /api/projects/:id/vote - التصويت على مشروع
GET /api/projects/:id/votes - الحصول على أصوات المشروع
```

### 9.3 المساهمات

```
POST /api/projects/:id/contribute - المساهمة في مشروع
GET /api/projects/:id/contributions - الحصول على مساهمات المشروع
GET /api/contributions/my - الحصول على مساهمات المستخدم
```

## 10. أمثلة الاستخدام

### مثال 1: اقتراح مشروع

```typescript
const proposalData = {
  title: 'إضاءة شارع الجمهورية',
  description: 'تركيب أعمدة إنارة في شارع الجمهورية',
  category: 'البنية التحتية',
  location: 'شارع الجمهورية - الحي الأول',
  targetAmount: 50000
};

const { data, error } = await supabase
  .from('project_proposals')
  .insert([proposalData])
  .select();
```

### مثال 2: التصويت على مشروع

```typescript
const { data, error } = await supabase
  .from('project_votes')
  .insert([
    {
      project_id: projectId,
      user_id: userId,
      vote_type: 'upvote'
    }
  ]);
```

### مثال 3: المساهمة في مشروع

```typescript
const { data, error } = await supabase
  .from('project_contributions')
  .insert([
    {
      project_id: projectId,
      user_id: userId,
      amount: 500,
      payment_status: 'completed',
      payment_reference: 'PAY-12345'
    }
  ]);
```
