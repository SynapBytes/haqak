# Roadmap — خارطة الطريق (مصر فقط / Independent)

> **ملاحظة:** Haqak مستقل وغير تابع لأي جهة حكومية.  
> الـ roadmap ده بيعكس أولويات المنتج من منظور Civic‑Tech مستقل.

---

## المرحلة الحالية — تثبيت الـ MVP

- [ ] تعريف حالات القضية (Issue Statuses) بشكل نهائي وانتقالاتها
- [ ] Audit trail: مين غيّر إيه وامتى (Hash Chain persistence)
- [ ] تحسين UX للأخطاء + الدخول + الصلاحيات
- [ ] تنظيم الـ docs وتقليل التكرار
- [ ] `.env.example` محدّث بكل المتغيرات المطلوبة

---

## اللي بعده — تقوية المنتج

- [ ] Supabase schema كامل + RLS policies (صلاحيات حقيقية)
- [ ] Notifications + realtime updates لتغييرات حالة القضية
- [ ] Ledger persistence: تخزين فعلي + تجربة "تحقق" للمستخدم
- [ ] MP account verification flow (اعتماد حسابات النواب)
- [ ] تحسين Mobile/PWA experience

---

## بعدين — مميزات متقدمة

- [ ] AI productionization: templates + review + moderation + rate limits
- [ ] Dashboards أعمق حسب الدائرة/المنطقة (GIS)
- [ ] مكتبة قوالب مخرجات (صياغات موحدة داخل المنتج)
- [ ] Consultative voting / priority polls (استطلاعات الأولويات)
- [ ] Analytics + تقارير دورية للدائرة

---

## خارج النطاق الحالي

- أي تكامل حكومي رسمي (ليس مخططًا في المرحلة الحالية)
- تمديد خارج مصر (ليس مخططًا حاليًا)
- مدفوعات/تمويل جماعي (ليس في MVP)
