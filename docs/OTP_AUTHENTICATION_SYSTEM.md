# نظام المصادقة عبر OTP - حقك

## نظرة عامة

تم إعادة هيكلة نظام المصادقة في منصة "حقك" ليعتمد على **رقم الهاتف والـ OTP** (One-Time Password) بدلاً من البريد الإلكتروني. هذا النظام يوفر أماناً أعلى وتجربة مستخدم محسّنة.

## المميزات الرئيسية

### 1. المصادقة عبر رقم الهاتف

- **التحقق الأساسي**: يتم التحقق من المستخدم باستخدام رقم هاتفه المصري (01xxxxxxxxx)

- **صيغة E.164**: تحويل تلقائي لأرقام الهاتف إلى صيغة دولية (+20xxxxxxxxx)

- **التحقق من الصيغة**: التحقق من صيغة رقم الهاتف قبل إرسال OTP

### 2. نظام OTP (رمز التحقق)

- **طول الرمز**: 6 أرقام عشوائية

- **صلاحية الرمز**: 5 دقائق

- **محاولات التحقق**: 3 محاولات فقط قبل الفشل

- **إعادة الإرسال**: إمكانية إعادة إرسال الرمز بعد انتهاء الصلاحية

### 3. نظام الموافقة للنواب

- **التحقق الأولي**: التحقق من رقم الهاتف والـ OTP

- **الموافقة الإدارية**: لا يمكن للنائب الوصول للوحة التحكم إلا بعد موافقة الإدارة

- **صفحة الانتظار**: صفحة مخصصة تعرض حالة الموافقة

- **التحديث التلقائي**: التحقق التلقائي من حالة الموافقة كل 10 ثوان

## مسارات المصادقة

### 1. تسجيل الدخول (Login)

```
1. إدخال رقم الهاتف
2. إدخال كلمة المرور
3. إرسال رمز OTP عبر SMS
4. التحقق من الرمز
5. تسجيل الدخول الناجح
```

### 2. التسجيل - مواطن (Signup Citizen)

```
1. إدخال البيانات الأساسية (الاسم، الهاتف، كلمة المرور)
2. إرسال رمز OTP عبر SMS
3. التحقق من الرمز
4. إنشاء الحساب
5. إعادة التوجيه لتسجيل الدخول
```

### 3. التسجيل - نائب (Signup MP)

```
1. إدخال البيانات الأساسية + بيانات النائب
   - الاسم الرباعي
   - اسم الشهرة (اختياري)
   - المحافظة
   - المركز/القسم
   - الدائرة الانتخابية
   - رقم القيد البرلماني (اختياري)
2. إرسال رمز OTP عبر SMS
3. التحقق من الرمز
4. إنشاء الحساب (حالة: قيد الانتظار)
5. إعادة التوجيه لصفحة الانتظار
6. بعد موافقة الإدارة → الوصول لوحة التحكم
```

### 4. استعادة كلمة المرور (Forgot Password)

```
1. إدخال رقم الهاتف
2. إرسال رمز OTP عبر SMS
3. التحقق من الرمز
4. إعادة تعيين كلمة المرور
```

### 2. الدوال السحابية (Edge Functions)

#### ملف: `supabase/functions/send-otp/index.ts`

**الوظيفة**: إرسال رمز OTP عبر Twilio

**المدخلات**:

```json
{
  "phone": "01012345678",
  "mode": "login|signup-citizen|signup-mp|forgot-password"
}
```

**العمليات**:

1. التحقق من صيغة رقم الهاتف

1. توليد رمز عشوائي 6 أرقام

1. تحويل الرقم إلى صيغة E.164

1. إرسال SMS عبر Twilio

1. حفظ الرمز في قاعدة البيانات مع صلاحية 5 دقائق

**المخرجات**:

```json
{
  "success": true,
  "message": "OTP sent successfully",
  "sid": "twilio_message_id"
}
```

#### ملف: `supabase/functions/verify-otp/index.ts`

**الوظيفة**: التحقق من رمز OTP

**المدخلات**:

```json
{
  "phone": "01012345678",
  "otp": "123456",
  "mode": "login|signup-citizen|signup-mp|forgot-password",
  "fullName": "أحمد محمد علي",
  "password": "SecurePass123",
  "governorate": "القاهرة",
  "district": "القاهرة",
  "electoralDistrict": "دائرة 1",
  "registrationNumber": "12345",
  "displayName": "أبو أحمد"
}
```

**العمليات**:

1. التحقق من صيغة الرمز (6 أرقام)

1. البحث عن الرمز في قاعدة البيانات

1. التحقق من عدم انتهاء صلاحيته

1. التحقق من عدم تجاوز محاولات التحقق

1. وضع علامة على الرمز كمستخدم

1. معالجة بناءً على النمط (mode)

**المخرجات** (للتسجيل):

```json
{
  "success": true,
  "email": "user_01012345678_1234567890@haqak.local",
  "phone": "+201012345678",
  "message": "OTP verified. Ready for signup."
}
```

### 3. قاعدة البيانات

#### جدول: `otp_codes`

```sql
CREATE TABLE otp_codes (
  id UUID PRIMARY KEY,
  phone TEXT NOT NULL,
  code TEXT NOT NULL,
  mode TEXT NOT NULL,
  attempts INTEGER DEFAULT 0,
  used BOOLEAN DEFAULT false,
  created_at TIMESTAMP,
  expires_at TIMESTAMP,
  used_at TIMESTAMP
);
```

#### جدول: `mp_approvals`

```sql
CREATE TABLE mp_approvals (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id),
  approved_by_admin_id UUID,
  status TEXT ('pending'|'approved'|'rejected'),
  rejection_reason TEXT,
  created_at TIMESTAMP,
  updated_at TIMESTAMP,
  approved_at TIMESTAMP
);
```

## تدفق الأمان

### 1. تشفير البيانات

- جميع الاتصالات عبر HTTPS

- تشفير البيانات في قاعدة البيانات

- عدم تخزين كلمات المرور بشكل مباشر

### 2. حماية من الهجمات

- **Rate Limiting**: تحديد عدد محاولات الإرسال

- **OTP Expiration**: انتهاء صلاحية الرمز بعد 5 دقائق

- **Attempt Limit**: 3 محاولات فقط للتحقق

- **Phone Validation**: التحقق من صيغة رقم الهاتف

### 3. سياسات الوصول (RLS)

- المستخدمون يرون بيانات أنفسهم فقط

- الإداريون يمكنهم إدارة الموافقات

- النواب يمكنهم رؤية حالة موافقتهم

## الاختبار

### اختبار تسجيل الدخول

```
1. أدخل رقم هاتف صحيح
2. أدخل كلمة مرور
3. اضغط "إرسال رمز التحقق"
4. انسخ الرمز من رسالة SMS
5. أدخل الرمز
6. اضغط "تحقق"
7. يجب أن تنجح عملية الدخول
```

### اختبار التسجيل - نائب

```
1. اختر "حساب نائب"
2. أدخل البيانات الكاملة
3. اضغط "إرسال رمز التحقق"
4. أدخل الرمز
5. يجب أن تنتقل لصفحة الانتظار
6. في لوحة الإدارة، وافق على الحساب
7. يجب أن ينتقل النائب لوحة التحكم
```

## استكشاف الأخطاء

### المشكلة: لم يصل الرمز

**الحل**:

- تحقق من رقم الهاتف

- تحقق من اتصال Twilio

- تحقق من رصيد Twilio

### المشكلة: الرمز منتهي الصلاحية

**الحل**:

- اطلب إعادة إرسال الرمز

- الرموز صالحة لمدة 5 دقائق فقط

### المشكلة: النائب لا يرى لوحة التحكم

**الحل**:

- تحقق من حالة الموافقة في قاعدة البيانات

- تأكد من أن `is_approved = true`

- تحقق من دور المستخدم
